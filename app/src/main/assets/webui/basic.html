Vervan Chat — Local API

Basic mode: OpenAI-compatible endpoints only. No chat interface is served here — turn on "Full web app" in Settings → Local API server for the browser chat experience.

Endpoints

  • GET /v1/models · GET /v1/models/{id}
  • POST /v1/chat/completions — stream, tools / tool_choice, response_format, vision and audio content parts, and reasoning_effort for models that support thinking (reasoning comes back as reasoning_content)
  • POST /v1/completions (legacy text completions)
  • POST /v1/embeddings — encoding_format: float or base64
  • POST /v1/audio/transcriptions (multipart file, or JSON base64)
  • POST /v1/audio/speech — returns wav or pcm
  • GET /health

With no model loaded, a request loads this device's default model automatically and unloads it again once it has been idle past the TTL set in Settings. /v1/models reports each model's state and ttl_expires_at.

curl http://127.0.0.1/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"…","messages":[{"role":"user","content":"Hello"}]}'

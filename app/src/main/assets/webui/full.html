API & OpenAPI spec

Point your own tools at this device.

This server is OpenAI-compatible, so most existing clients work by changing only the base URL. Generation, retrieval and speech all run on this device.

  • POST /v1/chat/completions — streaming, tools, vision, audio, reasoning_content
  • GET /v1/models · POST /v1/embeddings
  • POST /v1/audio/transcriptions · POST /v1/audio/speech
  • GET /health · GET /openapi.json

Beyond the standard body this build accepts thinking, app_tools, enabled_tools, knowledge_base_ids and chat_id (continue a stored chat, with its persona, history and knowledge bases applied server-side).
